# MOTION MESTRE

Levantamento de **onde nasce o motion design** de um reel no Editor 7.0, **quais princípios regem o resultado** e **quem controla**. Feito em 2026-11-12 sobre a `v9` (00.25). Cada arquivo aponta para o código e o texto que valem hoje; nada aqui substitui esses arquivos, só os organiza.

| Arquivo | O que separa |
|---|---|
| [01-quem-cria.md](01-quem-cria.md) | As quatro camadas que criam o movimento: roteiro, diretor, compositor e kit. Quem é modelo, quem é código, o que cada um recebe e entrega. |
| [02-principios.md](02-principios.md) | As regras que regem o resultado, por fonte: DIRETOR.md, GUIDE.md, brief.md, escolhas do usuário (formato, estilo, skill, ritmo), pacotes de ilustração. |
| [03-quem-controla.md](03-quem-controla.md) | As peneiras: lint do kit, checagem de layout no Chrome, pace.py, revisão humana. O que é erro, o que é aviso, o que ninguém mede. |
| [04-buracos.md](04-buracos.md) | O que não é controlado hoje e por quê; o que o Motion Think começa a fechar; os riscos de interpretação tripla e de estilo não verificado. |
| [05-mapa.md](05-mapa.md) | O fluxo inteiro em um diagrama de texto: da fala ao mp4, com o ponto exato em que cada decisão de motion é tomada e cada peneira roda. |

Ordem de leitura: 05 (o mapa), depois 01 a 04.
