# Créditos dos efeitos sonoros

Os arquivos desta pasta são renderizados pelo `scripts/make_sfx.py` a partir do banco de sons do
[earshot](https://github.com/Leonxlnx/earshot) v0.4.0, de Leon Lin, licença MIT. Cada entrada do `manifest.json`
diz em `source` o id do banco. Nenhuma gravação é distribuída: o banco guarda os sons como código (síntese) e,
para dois deles, como modelo ajustado de uma gravação CC0 1.0 do Freesound, que o earshot credita e nós também:

| nome | id | gravação | autor |
|---|---|---|---|
| `click` | `fit/click/floss_lid` | Plastic Clicks.flac (fs-167829) | qubodup |
| `key-press` | `fit/key/thock` | Keychron k10 A to + individual keys (fs-789628) | Sadiquecat |
